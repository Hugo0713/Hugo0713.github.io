Universal Test-Time Training

Qinzhe Hu*,Zefan Cai*,Ziqiao Ma,Hao Tan,Junjie Hu
* 共同第一作者
COLM 2026 Efficient Reasoning Workshop SpotlightICLR 2027 审稿中

把测试时训练的快权重在整个网络深度上共享，而不是每层各存一份私有状态；模型因此成为一个跨（块，层）的单一递归，并在相同状态规模下提升长上下文检索能力。

Universal Test-Time Training 架构图：展开的 uTTT 块，以及跨块共享的快权重专家池（uTTT-MoE）或共享稠密快权重算子（uTTT-Dense）。

Test-Time Generation

Zefan Cai,Qinzhe Hu,Yuchen Zhu,Hao Tan,Tianyuan Zhang,Sai Bi,Haoyi Qiu,Yicong Hong,Haozhe Zhao,Jason Kuen,Haoliang Wang,Ruiyi Zhang,Ryan A. Rossi,Wanrong Zhu,Molei Tao,Wen Xiao,Junjie Hu,Jiuxiang Gu
ICLR 2027 审稿中

用生成的方式读取快权重记忆：由 key 条件化的去噪读取采样一个值，而不是回归到条件均值，使压缩记忆能召回多个竞争值而非它们的平均，在相同状态规模下提升长上下文检索与新视角合成。

快权重记忆的确定性读取与生成式读取对比：平方损失下的读取返回条件均值，可能落在两个合理值之间；生成式读取则采样其中之一。

Last Layer KV Cache is All You Need

Zefan Cai,Sai Bi,Lin Zhang,Yicong Hong,Yuchen Zhu,Lu Li,Haozhe Zhao,Hanwen Jiang,Qinzhe Hu,Zeyi Huang,Shawn Lin,Cheng Luo,Chongjian GE,Rui-Jie Zhu,Xun Huang,Jiuxiang Gu,Junjie Hu,Hao Tan
ICLR 2027 审稿中

让每一层都只读取之前分块的最后一层 KV cache，把 Transformer 变成跨深度与时间的分块递归：长期 KV 存储缩减至约 1/L，而 124M 与 760M 上的 RULER 检索仍是所比较方法中最高的。

Transformer 与 LastKV 对比：标准 Transformer 每层保存各自的 KV 历史；LastKV 只保留已完成分块的最后一层 KV，并让后续分块的每一层读取它。

TF-MoE: Time-Frequency Mixture-of-Experts for Efficient Speech Separation

Qinzhe Hu,Chenda Li,Wangyou Zhang,Shujie Liu,Yan Lu,Yanmin Qian
INTERSPEECH 2026 Oral

在时间帧和梅尔频带两个维度上稀疏路由专家的混合专家框架，在几乎不增加推理开销的前提下提升语音分离模型的容量（Libri2Mix 上以相近的 4.1 GMACs/s 超过 BSRNN 3.8 dB SDR）。

TF-MoE 总览：梅尔子带切分的 Conformer 骨干、交替的频率维与时间维 MoE Conformer 块，以及带时间/子带路由器的稀疏 MoE 前馈模块。

SmartThinker: Progressive Chain-of-Thought Length Calibration for Efficient Large Language Model Reasoning

Chenzhi Hu,Qinzhe Hu,Yuhang Xu,Junyi Chen,Ruijie Wang,Shengzhong Liu,Jianxin Li,Fan Wu,Guihai Chen
ICML 2026

基于 GRPO 的高效推理方法，通过渐进式思维链长度校准为每道题估计最优推理长度并动态调整长度奖励系数，在 AIME25 等基准上最多减少 52% 推理 token 的同时提升准确率。

SmartThinker 优势计算流程：轨迹采样、按估计的最优长度计算长度奖励，以及不惩罚正确轨迹的动态奖励系数。
